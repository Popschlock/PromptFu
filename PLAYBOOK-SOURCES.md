# Where the playbooks came from

This file sits outside the skill folder, so no pass reads it and no skill mirror copies it. It records what each playbook's technique was drawn from when it was written (2026-09-18), so the provenance survives the 3.0 rewrite that took source lines out of the playbooks themselves.

Playbooks (`skills/promptfu/tasks/`) hold technique and name no model. Model facts live in `skills/promptfu/models/` and come from vendor documentation only. Several sources below are practitioner writeups, not vendor pages, and nothing in a playbook should be read as a vendor's claim about a model.
